# Projeto Individual - Breaking Bad

Website temático Breaking Bad com cadastro, login e dashboard. Projeto individual da faculdade SPTech, curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

Este site foi desenvolvido como Projeto Individual do semestre na SPTech. O tema Breaking Bad foi escolhido por ser uma série de que gosto, servindo como motivação para aplicar os conhecimentos das disciplinas. O projeto consolida o aprendizado de HTML, CSS, JavaScript, Node.js e banco de dados em uma aplicação completa.

## Para que serve

O site permite que visitantes se cadastrem, façam login e acessem um dashboard. O objetivo acadêmico é demonstrar a integração entre frontend, backend e banco de dados, aplicando validação de formulários, autenticação e exibição de dados.

## Funcionalidades
- Cadastro de usuários
- Login de usuários
- Dashboard

## Tecnologias usadas
- HTML
- CSS
- JavaScript
- Node.js
- MySQL
